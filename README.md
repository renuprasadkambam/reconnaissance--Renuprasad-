# Interactive OSINT Case File

A static, GitHub Pages-ready academic cybersecurity reconnaissance website.

## Files
- `index.html` — main report
- `style.css` — visual design
- `script.js` — navigation interactions
- `assets/` — supplied evidence screenshots

## Publish
1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Repository Settings → Pages.
4. Select **Deploy from a branch**.
5. Choose `main` and `/root`.
6. Save and wait for GitHub Pages to publish.
7. Submit the generated `https://USERNAME.github.io/REPOSITORY/` link.

## Scope
This report intentionally excludes the enrollment number and other unnecessary sensitive identifiers. It is designed for passive public-information reconnaissance only.
